# Завод роботов — решение для турнирной арены (спецификация v1)

Сервис управляет виртуальным заводом по [спецификации арены](https://arena.projectset.ru/docs?p=factory):
принимает заготовки, запускает станки, собирает роботов и продаёт их покупателям со скрытыми
предпочтениями. Описание стратегии — в [STRATEGY.md](STRATEGY.md).

Состав (всё на Node.js ≥ 18, **без внешних зависимостей**):

| Часть | Файлы |
|---|---|
| Алгоритм | `src/strategy.mjs`, `src/model.mjs` (байесовская модель покупателей) |
| API по спецификации | `server.mjs` — `/v1/health`, `/v1/info`, `/v1/runs/{runId}/start|event|finish|debug` |
| Интерфейс | `public/` — открывается на `http://localhost:4001/` |
| Собственный эмулятор | `src/engine.mjs` — движок завода с сидом; `cli.mjs` — сравнение стратегий |
| Стратегии-ориентиры | `src/baselines.mjs` — наивная, обучающаяся, оракул |
| Тесты | `test/check.mjs` — устойчивость и допустимость команд на разных мирах |

## Быстрый старт

```bash
node server.mjs                 # API + интерфейс на http://localhost:4001
PORT=8080 TOKEN=secret node server.mjs   # другой порт и проверка Authorization: Bearer secret
```

Откройте `http://localhost:4001/`, выберите номер мира и нажмите «Запустить симуляцию» —
смена пойдёт на экране. Прогоны, которые приходят от арены или песочницы, появляются
в списке «Прогон» автоматически.

## Интерфейс

* показатели: прибыль, выпуск, продажи, средняя цена, отказы, недопустимые команды, время ответа;
* графики по тактам: деньги, заполненность склада по видам предметов, загрузка каждого станка
  (диаграмма занятости и процент), выпуск и продажи нарастающим итогом;
* проигрыватель смены: ползунок или ▶ — состояние склада, станков и покупателей на любом такте;
  щелчок по графику переносит на этот такт;
* что алгоритм знает о покупателях: оценка цены по каждому типу с 80%-интервалом,
  предполагаемый образец, Pmax и f; после тренировочного прогона — сравнение с правдой;
* журнал сделок.

## Собственный эмулятор и сравнение

```bash
node cli.mjs --seeds 20                     # миры 1..20, все стратегии
node cli.mjs --seeds 5 --from 100           # миры 100..104
node cli.mjs --only bayes --verbose         # подробная статистика и оценки покупателей
node cli.mjs --url http://localhost:4001 --seeds 3   # прогнать запущенный сервис по HTTP, как арена
npm test                                    # устойчивость: 10 вариантов мира × 5 сидов
```

Эмулятор реализует правила спецификации: порядок событий в такте (`machine_done` → `supply` →
`idle`), `sale_result` следующими событиями того же такта, резерв места под работающие станки,
плату за хранение в конце такта, паузы покупателей, поправку цены ±2%, все причины отказа команд
из раздела 3.3. Миры детерминированы по номеру.

## Подключение к арене

1. Опубликуйте сервис по публичному адресу — хостинг или туннель, например:
   ```bash
   node server.mjs &
   cloudflared tunnel --url http://localhost:4001     # или: ngrok http 4001
   ```
2. В кабинете команды укажите выданный адрес (и токен, если запускали с `TOKEN`).
3. Нажмите «Проверить API», затем запустите тренировку на открытых мирах.
4. Для отладки без выкладки — страница «Песочница» на арене с адресом `http://localhost:4001`
   (CORS и `Access-Control-Allow-Private-Network` уже включены).

Состояние каждого прогона хранится в памяти по `runId`; знания о покупателях между прогонами
не переносятся. Сервис держит до 40 последних прогонов для интерфейса.

## Результаты (собственный эмулятор, 20 миров)

| Стратегия | Прибыль |
|---|---|
| наивная | 944 ± 1300 |
| обучающаяся | 4868 ± 1388 |
| **наша** | **7939 ± 818** |
| оракул (знает покупателей) | 8141 ± 849 |

0 недопустимых команд, максимальное время ответа ~30 мс (лимит 2000 мс).
